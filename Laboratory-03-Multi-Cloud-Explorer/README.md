# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview
This laboratory activity explores the world's leading public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP)[cite: 1]. Acting as part of the Cloud Evaluation Team at CloudNova Technologies, this mission focuses on analyzing cloud capabilities, comparing core services, and recommending the best cloud provider based on specific business scenarios[cite: 1].

## Objectives
* Explore the major public cloud platforms (AWS, Azure, GCP)[cite: 1].
* Identify and compare core cloud services across providers[cite: 1].
* Analyze business scenarios and recommend tailored cloud solutions[cite: 1].
* Document technical research and evaluation using Markdown[cite: 1].
* Relate Linux server environments to cloud hosting services[cite: 1].

## Linux Server Migration Analysis
From the KillerCoda Linux playground environment, the system parameters were identified:
* **Operating System:** Ubuntu 24.04 LTS (GNU/Linux)
* **CPU:** 4 vCPUs (Intel Xeon)
* **Memory:** 1.9 GiB RAM
* **Disk Space:** 7.6 GB

### Cloud Hosting Recommendations
If this Linux server environment were to be migrated to the cloud, it could be hosted using the following Virtual Machine services:
* **Amazon Web Services (AWS):** Amazon EC2 (Elastic Compute Cloud) - e.g., `t3.small` or `t4g.small` instance[cite: 1].
* **Microsoft Azure:** Azure Virtual Machines - e.g., `B1ms` or `B2s` burstable VM size[cite: 1].
* **Google Cloud Platform (GCP):** Google Compute Engine (GCE) - e.g., `e2-small` or `e2-medium` machine type[cite: 1].
