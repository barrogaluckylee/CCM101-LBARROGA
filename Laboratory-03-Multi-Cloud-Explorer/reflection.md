# Checkpoint 8 – Mission Reflection

## Mission Reflection

Completing the Multi-Cloud Explorer lab gave me a clearer, hands-on understanding of how major cloud platforms operate. Comparing AWS, Microsoft Azure, and Google Cloud Platform highlighted how each provider serves unique infrastructure needs. I found Amazon Web Services (AWS) particularly interesting due to its massive service ecosystem covering compute, storage, databases, and networking.

During this investigation, I realized that while these cloud providers offer equivalent core capabilities—like virtual machines, object storage, and identity management—their primary strengths differ significantly:

* **AWS** excels in overall platform breadth, ecosystem size, and scalability.
* **Microsoft Azure** seamlessly integrates with enterprise environments using Active Directory and Windows Server.
* **Google Cloud Platform (GCP)** leads in container orchestration with GKE and high-performance machine learning workflows.

A key takeaway from this activity is that choosing a cloud provider isn't about finding a single "best" platform. Instead, it requires evaluating specific organizational constraints such as existing software stacks, technical expertise, compliance needs, and total budget. 

Documenting this project in Markdown and managing the file structure on GitHub helped reinforce both my technical cloud knowledge and my ability to organize documentation effectively.
