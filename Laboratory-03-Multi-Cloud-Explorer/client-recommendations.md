# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

I would choose AWS for the startup because it provides a practical way to build an application without requiring the company to purchase and maintain its own servers. The startup can begin with a basic cloud environment and expand its resources as the number of users and business activities increase. This makes AWS a suitable platform for a company that wants to keep its initial expenses manageable while having room for future expansion.

AWS services can support the main parts of the mobile application. EC2 can provide the computing environment, S3 can handle file storage, and DynamoDB can manage application data.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

I recommend Microsoft Azure for the university because it integrates directly with their existing infrastructure, such as Windows Server, Active Directory, and Microsoft 365. Migrating to Azure allows the university to extend their current user accounts and settings smoothly without rebuilding their identity systems from scratch.

The university can use Azure Virtual Machines to host academic tools, Microsoft Entra ID for single sign-on user accounts, and Azure SQL Database for student records.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform is the best choice for an AI research company because of its specialized high-performance hardware and deep integration with artificial intelligence tools. GCP offers Tensor Processing Units (TPUs) specifically designed to accelerate complex machine learning models.

The company can utilize Google Compute Engine GPU instances for training, Vertex AI for managing machine learning workflows, and Cloud Storage for massive research datasets.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for a global e-commerce company because of its high availability, global footprint, and reliable auto-scaling features. AWS can automatically adjust server capacity during traffic surges, ensuring that the online store remains responsive to customers worldwide.

The company can use Amazon CloudFront to deliver fast web content globally, AWS Auto Scaling to handle unexpected visitor spikes, and Amazon Aurora for fast, multi-region database processing.

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| **Startup Company** | AWS | Pay-as-you-go pricing, scalability, and startup support programs. |
| **Enterprise Organization** | Azure / AWS | Proven reliability, strict security compliance, and robust technical support. |
| **Microsoft Environment** | Microsoft Azure | Direct integration with Active Directory, Windows Server, and Office 365. |
| **AI / Machine Learning** | GCP | Advanced machine learning infrastructure, TPUs, and Vertex AI suite. |
| **Kubernetes Deployment** | GCP | Creator of Kubernetes with the most mature managed service (GKE). |
| **Global Web Application** | AWS | Extensive availability zones, fast content delivery (CDN), and auto-scaling. |
